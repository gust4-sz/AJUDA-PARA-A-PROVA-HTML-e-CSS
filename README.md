# 📚 AJUDA PARA A PROVA HTML e CSS

## 📌 Sobre o projeto

O **AJUDA PARA A PROVA HTML e CSS** é um projeto desenvolvido com o objetivo de auxiliar nos estudos de desenvolvimento web, reunindo conceitos fundamentais de **HTML5 e CSS3** para facilitar a revisão dos conteúdos e a preparação para provas.

O projeto busca proporcionar uma maneira simples e prática de revisar conceitos, compreender a estrutura de páginas web e aprender como aplicar estilos visuais utilizando CSS.

## 🎯 Objetivos

- 📖 Revisar os principais conceitos de HTML5.
- 🎨 Estudar estilização e formatação com CSS3.
- 💻 Praticar a criação e organização de páginas web.
- 🧠 Facilitar a memorização dos conteúdos estudados.
- 🚀 Desenvolver conhecimentos fundamentais para projetos futuros de desenvolvimento web.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização, cores, layouts e apresentação visual.

## 📖 Conteúdos estudados

### HTML5
- Estrutura básica de um documento HTML.
- Tags e elementos HTML.
- Títulos, parágrafos e links.
- Imagens e listas.
- Formulários e campos de entrada.
- Organização semântica do conteúdo.

### CSS3
- Seletores e propriedades.
- Cores, fontes e backgrounds.
- Margens, espaçamentos e bordas.
- Modelo de caixas (*Box Model*).
- Classes e identificadores.
- Flexbox e organização de layouts.
- Responsividade e media queries.

## ▶️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo `index.html`.
4. Abra o arquivo no navegador ou utilize a extensão Live Server para visualizar a página.
5. Edite o HTML e o CSS para praticar e testar seus conhecimentos.
